## 🔬 Thesis Projects – RNA Secondary Structure

> *Working with RNA secondary structures? These libraries help you handle formats without the headache.*

- **[RNA2DUnifier](https://github.com/bdslab/RNA2DUnifier)** – Unifies different RNA secondary structure outputs into the **BPSeq** format.  
- **[RNA2DFormatIO](https://github.com/bdslab/RNA2DFormatIO)** – Converts RNA secondary structures **to/from** multiple formats (CT, DB, BPSeq, etc.) with a clean I/O interface.
